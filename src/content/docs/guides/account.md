### 概述

房间号、身份码、弹幕服务器连接与倒计时结束后行为等账号相关设置。

## 配置项

| 配置项 | 默认值 | 说明 |
| ------ | ------ | ---- |
| `room_id` | `""` | 房间号，程序会据此获取礼物数据 |
| `host` | `"127.0.0.1"` | 监听地址，默认本机 |
| `port` | `65000` | 监听端口，控制面板与 OBS 浏览器源的访问端口 |
| `auth_code` | `""` | 主播身份码，从幻星互动玩法页面获取 |
| `exit_timer` | `True` | 是否启用倒计时结束后退出程序 |
| `exit_time` | `1800` | 倒计时结束后退出程序的等待时间（秒） |

## 开关

- **连接至弹幕服务器**：连接至弹幕服务器，只有连接成功后才能收到弹幕与礼物事件
- **忽略倒计时**：启用时在倒计时结束后（包括暂停时）仍然会触发加减时，与「倒计时结束后断开连接」互斥
- **倒计时结束后断开连接**：倒计时结束后是否断开弹幕服务器连接，与「忽略倒计时」互斥，可设置延迟时间

### 注意事项

- 幻星平台应用拥有冷却期，断开连接后建议等待一分钟再重新连接，否则可能会导致连接失败
- 程序会在退出时尝试自动断开连接，如断开失败会导致幻星返回房间重复游戏的错误，需等待一分钟后才能重新连接
- 每个直播间同时只能有 5 个连接，如超过 5 个连接会导致应用掉线，目前暂不清楚连接数量的具体计算方式，不建议同时使用过多的幻星玩法
