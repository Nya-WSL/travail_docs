### 倒计时（倒计时所有单位都是秒）

- **加时**：赠送设定的礼物可以增加总时长
- **减时**：赠送设定的礼物可以减少总时长
- **加倍**：赠送设定的礼物可以增加当前总时长的一半，总时长 × 2 的礼物数量次方
- **减半**：赠送设定的礼物可以减少当前总时长的一半，总时长 ÷ 2 的礼物数量次方
- **清空**：赠送设定的礼物可以清空当前总时长，一次赠送多个礼物仅计算一次
- **随机**：赠送设定的礼物可以随机增加/减少手动设定范围的总时长，一次赠送多个礼物则每个礼物都会随机一个值，最后计算总和

### 随机权重

> 从最小数~最大数中抽取一个随机整数，每个数概率均匀分布（基于拒绝采样的梅森旋转算法），即 Python 的 `random.randint()`，在加班姬中称为默认算法。

- 随机玩法的权重可自定义：若概率分别为 0.55 / 0.3 / 0.15，则有 55% 概率减时、30% 概率不变、15% 概率加时
- 某一项概率为 0 时该项不生效
- 三个概率均为 0 时使用默认算法
- 判断顺序为：减时 -> 不变 -> 加时
- 概率可设为 0~1 之间的两位小数（0 和 1 除外），实际概率可能为 0.555，最终会四舍五入为 0.56
- 若随机最小数不为负数或最大数不为正数，减时/加时概率必须为 0，否则使用默认算法

### 盲盒

- 如果设定了盲盒内礼物的时长，收到该礼物时会识别为礼物本身而不是盲盒
- 未设置盲盒内礼物时，收到盲盒内礼物将按盲盒处理
- 盲盒数据通过服务器获取（需 cookie 鉴权），可能存在小号被风控或登录失效导致无法获取的风险
