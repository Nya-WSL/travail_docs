## 按钮

- **开始**：开始倒计时，未连接弹幕服务器时按钮不可用
- **暂停**：暂停倒计时，倒计时未开始时按钮不可用
- **继续**：继续倒计时，倒计时未暂停时按钮不可用
- **停止**：停止倒计时，倒计时未开始时按钮不可用，停止后会清空时间
- **增加**：手动增加倒计时时间，倒计时未开始时按钮不可用，可在倒计时运行时使用
- **减少**：手动减少倒计时时间，倒计时未开始时按钮不可用，可在倒计时运行时使用
- **保存**：将当前倒计时以指定名称保存
- **读取**：读取倒计时数据，读取时会覆盖当前倒计时，可在倒计时运行时使用
- **设置礼物**：打开礼物设置界面，设置自定义礼物的加时/减时/加倍/减半/清空/随机规则
- **更新礼物**：手动更新礼物数据，程序会在连接弹幕服务器后自动更新
- **盲盒盈亏**：查看盲盒礼物的盈亏统计
- **礼物统计**：查看加班姬运行期间的礼物统计（数量与电池），启动时清零
- **登录账号**：跳转至幻星互动玩法页面获取身份码，需要手动输入身份码
- **检查更新**：手动检查更新，程序会在启动时自动检查一次更新
- **更新日志**：查看更新日志
- **上传日志**：上传日志到服务器，用于调试和反馈问题，只会上传本次运行产生的日志
- **发送模拟礼物**：在模拟测试器中发送模拟礼物，用于离线测试礼物玩法效果
- **确认重置**：确认重置所有礼物配置
- **取消重置**：取消重置操作
- **删除**：删除选中的礼物或玩法配置
- **提交**：保存当前礼物设置
- **重置全部**：清空所有礼物与玩法配置
- **关闭**：关闭当前弹窗
- **清零**：清空盲盒盈亏统计数据
- **确定**：确认执行当前操作
- **取消**：取消当前操作
- **使用本地数据重置**：使用本地预置礼物数据重置礼物列表
- **更新**：从选定的更新源下载并更新程序
- **是**：确认覆盖已存在的保存数据
- **否**：取消覆盖，返回保存弹窗
- **加载**：加载选中的倒计时存档

### 颜色设置

- **按钮颜色**：自定义界面按钮的颜色
- **文字颜色**：自定义界面文字的颜色
