- **开始**：开始倒计时，未连接弹幕服务器时按钮不可用
- **暂停**：暂停倒计时，倒计时未开始时按钮不可用
- **继续**：继续倒计时，倒计时未暂停时按钮不可用
- **停止/重置**：停止倒计时，倒计时未开始时按钮不可用，停止后会清空时间；若程序在倒计时未清零时退出，重新启动后按钮会显示为**重置**，用于清空继承的倒计时数据
    - 加班姬会尝试在程序报错、崩溃和退出时自动保存倒计时数据，在程序重新启动后会自动加载倒计时数据，如果需要手动保存倒计时数据，请使用**保存**按钮
- **增加/减少**：手动增加/减少倒计时时间，倒计时未开始时按钮不可用，可在倒计时运行时使用（这算是给主播准备的小手段吗x
- **保存/读取**：保存/读取倒计时数据，保存时需要填写保存名称，读取时可以选择已保存的名称进行加载或删除；读取时会覆盖当前倒计时，可在倒计时运行时使用
    - 该功能可能会缓解加班姬因为端口占用导致的无法多开问题

### 账号设置

- **身份码**：输入幻星平台的身份码，连接弹幕服务器后显示房间号和登录状态
- **连接至弹幕服务器**：连接至弹幕服务器，只有连接成功后才能收到弹幕
- **忽略倒计时**：启用时在倒计时结束后（包括暂停时）仍然会触发加减时，与**倒计时结束后断开连接**互斥
- **倒计时结束后断开连接**：倒计时结束后自动断开弹幕服务器连接（避免被B站统计无效的运行时间），可设置延迟断开时间（秒），与**忽略倒计时**互斥

### 礼物设置

- **设置礼物**：打开礼物设置界面，为礼物设置**加时 / 减时 / 加倍 / 减半 / 清空 / 随机**玩法规则
- **更新礼物**：手动更新礼物数据

### 显示设置

- **无边框倒计时**：切换倒计时的显示模式，无边框倒计时使用label实现，而边框使用badge实现
- **OBS显示排行榜**：是否在浏览器源中显示排行榜
- **OBS显示投喂记录**：是否在浏览器源中显示礼物记录

### 外观设置

- **计时颜色**：设置倒计时时间的颜色
- **按钮颜色**：设置按钮的颜色
- **文字颜色**：设置文字的颜色
- **背景颜色**：设置控制面板的背景颜色

### 统计相关

- **盲盒盈亏**：查看运行期间盲盒的盈亏统计，启动加班姬时清零
- **礼物统计**：查看运行期间收到的礼物统计，启动加班姬时清零

### 程序设置

- **登录账号**：跳转至幻星平台获取身份码的页面，需要手动输入身份码
- **检查更新**：手动检查更新，程序会在启动时自动检查一次更新
- **更新日志**：查看更新日志
- **上传日志**：上传日志到服务器，用于调试和反馈问题，上传日志只会上传加班姬本次运行产生的日志，不会上传历史日志；在上传日志前请确保日志中没有包含敏感数据
- **自动检查更新**：开关程序启动时自动检查更新

### 模拟测试

- **模拟测试**：礼物模拟测试器，用于离线测试礼物的玩法效果，需要先开始倒计时再发送模拟礼物

### 工单系统

- 控制面板右下角提供了**提交工单**和**查看工单**的浮动按钮，支持Bug反馈和功能请求
